# 关键词哨兵 下载页

本地单机的网站关键词监控程序。你把要盯的网址和关键词填进去，它按每个网站各自的频率自动翻页抓正文，命中了就记下来，可以在软件里看、复制、导出。

**所有数据只存在你自己这台电脑上。** 软件不连任何服务器、没有账号、不上云、不统计。除了去访问你自己添加的那些网站，它不出网。

## 运行要求

- Windows 10 或 11，64 位。
- WebView2 运行时。Win10 1803 及以上、以及 Win11 一般系统自带；打开是空白窗口的话去装 [Evergreen WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
- 不需要 Python、不需要 Node、不需要联网安装任何东西。

## 第一次用

1. 打开程序，左侧点**网站**，点**添加网站**。
2. 填网站名称（自己认得出就行）、要盯的页面地址、关键词（多个用逗号或顿号分开）。
3. 保存后选中这个网站点**立即扫描**，或者什么都不做——到了它自己那个扫描时间它会自动跑。
4. 抓到的内容在**命中信息**里。点一行看全文，可以复制、打开原页、导出 CSV。

想改抓取深度、翻页上限、并发数、全局频率，都在**设置**里。

## 数据存在哪

`%APPDATA%\com.sentry.kwmonitor\sentry.db`（SQLite 单文件，带 WAL）。

换电脑就整份拷这个文件；卸载程序默认不会删它，重装后原来的网站和命中记录还在。要彻底清空，删掉 `com.sentry.kwmonitor` 这个目录。

当前 0.2.0，构建于 2026-10-01 22:25。新增"纯 JS 页面"一档设置：正文靠脚本现拼的页面用系统自带的浏览器内核在屏幕外渲染后取全文，不额外装浏览器。0.1.0 的安装版与 msi 仍留在开发机的 `发布版/存档_0.1.0/`（那份免安装单文件在本地被这一版同名覆盖），要下旧版直接从 Release v0.1.0 取三件。

## 已知边界

- 需要登录才能看到的页面抓不到，它不带你的 cookie。
- 纯 JS 渲染的页面靠系统自带的 WebView2 内核在屏幕外跑脚本取正文，设置里默认"认出空壳才渲染"；提交表单那种站内搜索（POST）取不到，渲染超时或失败的站会如实标成"有盲区"。
- 反爬严格的站可能返回 403 或验证码，软件会把失败如实报在扫描记录里，不会伪造结果。
